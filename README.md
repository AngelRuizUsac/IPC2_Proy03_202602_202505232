# Proyecto 3 — v0.2.0: API y persistencia

Angel Daniel Ruiz Ramos · 202505232 · Sección C

Añade la API HTTP, actualización de RTU, autorización de documentos, persistencia, inicialización, consultas y ejemplos de entrada.

## Abrir y compilar

Requiere SDK .NET 10 y las herramientas de ASP.NET de Visual Studio para las etapas web. Abrir `Proyecto3.sln` o ejecutar `dotnet build Proyecto3.sln -c Release` desde esta carpeta.

Ejecutar `dotnet run --project Backend/Backend.csproj`. La API queda en `http://localhost:5303`. Usar Postman o un cliente HTTP y los ejemplos incluidos. Consultar `documentacion/API.md`.

## Alcance de esta etapa

No incluye interfaz web ni ensayo final. La guía general de ejemplos describe también las pantallas que se incorporan en la versión siguiente; en esta etapa los archivos se envían como cuerpo JSON desde un cliente HTTP.

Esta es una etapa acumulativa preparada el 19 de octubre de 2026 a partir del proyecto completo. No representa un avance fechado en una semana anterior. Consultar RELEASE.md para la descripción que acompaña a esta versión.
